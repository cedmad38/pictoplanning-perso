# PictoPlanning Perso

Version Windows de PictoPlanning (planning visuel par pictogrammes).

## Installation

1. Télécharger le fichier `PictoPlanning-Perso-…-windows.zip` dans la rubrique **Releases**.
2. Clic droit sur le zip, **Extraire tout**, dans un dossier à conserver (Documents par exemple).
3. Double-clic sur **PictoPlanning Perso.exe**.
4. Au premier lancement, Windows affiche « Windows a protégé votre ordinateur » : cliquer **Informations complémentaires**, puis **Exécuter quand même**.

Windows 10 ou 11, 64 bits. Les plannings restent enregistrés sur l'ordinateur.
